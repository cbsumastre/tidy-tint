# Code of Conduct

This project aims to be a welcoming place for everyone, regardless of
background, identity or level of experience.

## Expected behavior

- Be respectful and assume good intent.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its users.

## Unacceptable behavior

- Harassment, insults, or personal or political attacks.
- Discriminatory language or imagery.
- Publishing others' private information without permission.
- Any conduct that would be inappropriate in a professional setting.

## Enforcement

The maintainer may edit or remove comments, issues and pull requests that
break this code, and may block contributors who repeatedly do so.

To report a problem, contact the maintainer at cbsumastre@gmail.com. Reports will be
handled privately.

This code of conduct is inspired by the
[Contributor Covenant](https://www.contributor-covenant.org/).
